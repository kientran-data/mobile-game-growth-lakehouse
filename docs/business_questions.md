# Business Questions

These are the primary business questions the platform must answer.

| Domain | Business Question |
| --- | --- |
| Executive | How are DAU, revenue and profitability trending? |
| Executive | Which game contributes the most revenue? |
| Executive | Which game has the strongest growth potential? |
| UA | How much are we spending by channel/campaign? |
| UA | What is CPI by campaign, country and platform? |
| UA | Which campaigns acquire the highest-quality users? |
| UA | Which campaigns should be scaled or stopped? |
| Retention | What are D1, D7 and D30 retention rates? |
| Retention | Which acquisition sources generate the best retention? |
| Retention | How does retention differ by game/version/country? |
| Product | What are DAU/WAU/MAU trends? |
| Product | How many sessions does a player generate? |
| Product | Did a new app version improve or reduce engagement? |
| Game Design | At which levels do players drop off? |
| Game Design | Which levels have abnormally high failure rates? |
| Monetization | What is Ad Revenue vs IAP Revenue? |
| Monetization | What is ARPDAU by game/country/platform? |
| Monetization | What percentage of players become payers? |
| Profitability | What is player/cohort LTV? |
| Profitability | What are D0/D1/D7/D30 ROAS by campaign? |

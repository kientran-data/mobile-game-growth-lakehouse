# Dataset: game_events

## Overview
Continuous game activity events from players.

## Source System
Game Client SDK

## Business Purpose
Track player engagement, progression, and funnel.

## Grain
One row represents one event generated by one player at one event timestamp.

## Keys
- Primary Key: `event_id`

## Delivery Pattern
Continuous game activity -> SDK buffers events -> micro-batch JSON files -> Landing Zone (5-15 min frequency)

## Mutability
Append-only. (But duplicate delivery, late arrival, malformed events can occur).

## Schema

| Column | Type | Nullable | Description |
|---|---|---|---|
| `event_id`         | STRING    |       No | Unique event ID             |
| `player_id`        | STRING    |       No | Player identifier           |
| `game_id`          | STRING    |       No | Game identifier             |
| `session_id`       | STRING    |      Yes | Player session              |
| `event_name`       | STRING    |       No | Event type                  |
| `event_timestamp`  | TIMESTAMP |       No | Business event time UTC     |
| `platform`         | STRING    |       No | android / ios               |
| `country`          | STRING    |      Yes | ISO country code            |
| `app_version`      | STRING    |       No | App version at event time   |
| `device_id`        | STRING    |      Yes | Synthetic device identifier |
| `level_id`         | INTEGER   |      Yes | Gameplay level              |
| `currency_type`    | STRING    |      Yes | coins / gems                |
| `currency_amount`  | DOUBLE    |      Yes | Economy amount              |
| `event_properties` | JSON/MAP  |      Yes | Flexible custom properties  |

## Business Rules
Event names V1: `app_open`, `session_start`, `session_end`, `tutorial_start`, `tutorial_complete`, `level_start`, `level_complete`, `level_fail`, `currency_earned`, `currency_spent`.
`event_timestamp` is the time the event actually occurred on the client.

## Data Quality Expectations
- `event_id`, `player_id`, `game_id`, `event_name`, `event_timestamp` NOT NULL
- `platform` IN ('android', 'ios')
- `level_id` NULL is not an error for non-level events (e.g., `app_open`)
